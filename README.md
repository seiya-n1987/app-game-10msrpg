# 10分RPG - タクティカルバトル

10分で楽しめるシミュレーションRPG Webアプリケーション

## 特徴

- **10分でクリア可能**: 短時間で楽しめる戦術バトル
- **ランダム生成**: アクセス毎に地形、ユニット配置が変化
- **PWA対応**: オフラインでもプレイ可能
- **FFT風の世界観**: Final Fantasy Tacticsにインスパイアされた中世ファンタジー

## ゲームシステム

### ユニットクラス
- **戦士**: HP高、バランス型
- **弓兵**: 射程3の遠距離攻撃
- **魔道士**: 高火力、低防御
- **騎士**: 高移動力、高防御
- **僧侶**: サポート型

### 地形効果
- **草原**: 移動コスト1、防御+0
- **森**: 移動コスト2、防御+20
- **山**: 移動コスト3、防御+30
- **水**: 移動不可
- **道**: 移動コスト1、防御+0

## セットアップ

### アイコン生成

PWAアイコンを生成するには、`generate-icons.html`をブラウザで開いて、表示されるリンクから以下のファイルをダウンロードしてください：

- `icon-192.png`
- `icon-512.png`

ダウンロードしたファイルをプロジェクトのルートディレクトリに配置してください。

### ローカルサーバーでの起動

```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合 (http-serverをグローバルインストール)
npx http-server -p 8000
```

ブラウザで `http://localhost:8000` にアクセスしてゲームを開始します。

## 遊び方

1. **戦闘開始**: タイトル画面で「戦闘開始」ボタンをクリック
2. **ユニット選択**: 味方ユニット(緑枠)をクリックして選択
3. **アクション選択**:
   - **移動**: 移動可能範囲(青)が表示され、クリックで移動
   - **攻撃**: 攻撃可能範囲(赤)が表示され、敵をクリックで攻撃
   - **待機**: 行動を終了
4. **ターン終了**: 全ユニットの行動後、「ターン終了」で敵ターンへ
5. **勝利条件**: 敵ユニットを全滅させる

## 技術スタック

- **HTML5 Canvas**: グラフィックス描画
- **Vanilla JavaScript**: ゲームロジック
- **CSS3**: UIスタイリング
- **PWA**: Service Worker + Manifest
